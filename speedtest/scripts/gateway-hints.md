# 网关 / 劫持恢复提示

本工具的 Web 界面**不会**静默修改系统网关或 DNS。以下操作请在本机手动完成，并先记录修改前状态。

## 先确认症状

1. 打开「测网速」修复面板，查看当前 DNS 与探测结论  
2. 若出现「NXDOMAIN 劫持」：优先更换可信公共 DNS（阿里 / 腾讯 DNSPod）  
3. 若国内站点都超时：检查 Wi‑Fi、网线、路由器，或重启光猫/路由器  
4. 若仅国际站点失败：可能是线路/防火墙限制，不一定是本机故障  

## 查看默认网关

| 系统 | 命令 |
|------|------|
| Linux | `ip route show default` |
| macOS | `route -n get default` |
| Windows | `ipconfig` 或 `Get-NetRoute -DestinationPrefix '0.0.0.0/0'` |

常见家用网关：`192.168.0.1` / `192.168.1.1` / `192.168.31.1`（小米）等。

## 路由器被改 DNS 时

1. 浏览器打开网关地址（如 `http://192.168.1.1`）  
2. 用路由器管理密码登录  
3. 找到「DHCP / DNS / 上网设置」，核对 DNS 是否被改成陌生地址  
4. 改回「自动」或填入推荐公共 DNS，保存并重启路由器  

## 本机 Hosts 劫持

恶意软件有时会改 hosts：

- Windows: `C:\Windows\System32\drivers\etc\hosts`
- macOS / Linux: `/etc/hosts`

若发现百度、淘宝等域名被指向奇怪 IP，先备份再删除可疑行（需管理员权限）。

## 安全原则

- 任何「一键修复」都必须由你本人确认  
- 脚本会打印修改前后状态，并写入 `~/.cewangsu-dns-backup/`（Windows 同路径用户目录）  
- 不确定时只使用面板里的「检测」与「复制命令」，不要执行来路不明的提权脚本
